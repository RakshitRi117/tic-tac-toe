# 🎮 Tic‑Tac‑Toe — Python Console Game

A simple yet polished console‑based Tic‑Tac‑Toe game built in Python.  
This project marks my first independent software build — a milestone in my journey as a developer learning Python fundamentals, clean code structure, and version control with Git.

---

## 🧠 About the Project
This game is a two‑player Tic‑Tac‑Toe implementation that runs entirely in the terminal.  
It focuses on **clarity, logic, and user experience**, using color‑coded output for better readability.

---

## ✨ Features
- 🎨 **Colored board display** — X in red, O in green (powered by `colorama`)
- 🔁 **Turn cycling** — handled elegantly with `itertools.cycle`
- 🧩 **Win detection** — checks rows, columns, and diagonals
- 🚫 **Invalid move handling** — prevents overwriting existing cells
- 🤝 **Draw detection** — announces when the board is full
- 🧱 **Clean grid layout** — easy to read and visually balanced
